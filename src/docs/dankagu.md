## 账号登录

1. 下载并安装对应平台的游戏客户端。

   - **Android**：不能与原客户端共存，可直接安装
   - **iOS**：可与原客户端共存，需[自行签名](#常见问题)

2. 打开游戏，同意条款。

3. 点击「**サインインとは？**」按钮。

![Step3](/images/dankagu/signin-1.jpg)

4. 点击「**ゲストモードでプレイ**」按钮。

![Step4](/images/dankagu/signin-2.jpg)

5. 勾选「**上記に同意します**」

6. 若要创建新账号，请看 **步骤7** ，若要引继旧帐号，请看 **步骤8**

![Step5](/images/dankagu/signin-3.jpg)

7. 点击「**新規データでプレイ**」按钮创建新账号。

8. 点击「**続きからプレイ**」按钮，输入您设置的`引继ID`和`密码`并点击「**ＯＫ**」按钮。

![Step6](/images/dankagu/signin-4.jpg)

9. 账号登录完成，开始游玩，我们建议您在完成新手引导后设置[账号继承](#账号继承)。

## 账号继承

::: tip

- 设置账号继承后，您的账号数据可以在新设备登陆时被继承
- 继承码一旦设置，永久有效
- 新的引继码设置后，旧的引继码自动失效

:::

1. 点击主界面右上角设置按钮

![Step1](/images/dankagu/transfer-1.jpg)

2. 点击「**アカウント設定**」按钮

![Step2](/images/dankagu/transfer-2.jpg)

3. 点击「**引き継ぎID/パスワード登録**」按钮

![Step3](/images/dankagu/transfer-3.jpg)

4. 设置8位以上引继ID及密码，点击「**登録**」按钮

![Step4](/images/dankagu/transfer-4.jpg)

## 常见问题

::: tip iOS如何安装？

- 如果您的设备支持[TrollStore](https://ios.cfw.guide/installing-trollstore/): 使用[TrollStore](https://ios.cfw.guide/installing-trollstore/)直接安装tipa
- 如果不支持，请使用证书或者使用[Sideloadly](https://libshortcut.com/blog/install-ipa-with-sideloadly/)自行签名(每7天重签)

:::

::: info 安卓/华为设备无法注册/登录

ダンカグ Reborn 要求设备有GMS框架，请安装GMS后重新打开游戏

:::

::: info 退出以后黑屏打不开

请不要在下载数据过程中退出游戏，否则您可能需要清除数据/重新安装

:::

::: info 缺歌、玩不了弹幕模式怎么办？

复兴神社、推进游戏进度即可解锁

:::

::: info 缺抽卡、养成资源怎么办？

资源会通过每日邮件发放

:::
